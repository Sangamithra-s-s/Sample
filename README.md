# Test Repository

This repository is created just for **testing and understanding how GitHub Issues works**.

It's a practice space to explore how issues can be created, assigned, labeled, discussed, and closed with multiple collaborators — not an actual project repo.

## Purpose

- To understand the GitHub Issues workflow hands-on
- To try creating, assigning, and closing issues with collaborators
- To explore labels and how they're used to organize issues

## Note

This repo is for learning purposes only and is not part of any final project submission.😌😌
